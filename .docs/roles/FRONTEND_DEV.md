# Role: Frontend Developer (React Native)

## 1. Trách nhiệm (Responsibilities)
- Lập trình giao diện ứng dụng trên nền tảng React Native dựa trên bản thiết kế Figma.
- Xử lý các luồng UX/UI mượt mà, bao gồm cả hiệu ứng (Animations) cho tính năng "Quay random món ăn".
- Đảm bảo ứng dụng responsive, hiển thị tốt trên nhiều kích cỡ màn hình iOS và Android.
- Tích hợp API và các logic kết nối với Firebase & Local SQLite.
- Xử lý Global State (Redux/Zustand) để lưu giữ thông tin user, danh sách món ăn đã tải.

## 2. Kỹ năng yêu cầu
- Thành thạo JavaScript/TypeScript và hệ sinh thái React Native.
- Có kinh nghiệm làm việc với React Navigation.
- Hiểu biết về vòng đời component và tối ưu hiệu suất (memo, useMemo, useCallback).
- Có khả năng cấu hình và build app ra file cài đặt (APK, AAB, IPA).

## 3. Quy trình làm việc (Workflow)
1. Nhận task từ board.
2. Kiểm tra design trên Figma.
3. Tạo branch mới (`feature/ten-tinh-nang`).
4. Code và tự test (trên cả simulator và máy thật).
5. Tạo Pull Request và nhờ review code.
